# 🌐 Traffic Monitoring Website

A lightweight website for analytics, performance monitoring, and traffic observation. This project is designed to help understand usage patterns, improve user experience, and maintain service reliability.

---

## 📌 Overview

This site provides a transparent interface for visitors while collecting basic, non-intrusive analytics data for operational and statistical purposes.

It is built to work with **Cloudflare Pages** and serverless functions for routing and monitoring.

---

## 🚀 Features

- 📊 Traffic analytics and monitoring
- 🌍 Country-level geographic insights
- ⏱️ Visit timestamps tracking
- 🧭 Page request tracking
- 🧠 Browser and device information collection
- ⚡ Cloudflare Pages deployment support
- 🔒 Transparent visitor notice

---

## ⚙️ How It Works

- The **public/** directory serves the frontend static site.
- The **functions/** directory contains Cloudflare Pages Functions for handling dynamic routing and request processing.
- Visitor data is processed for analytics and performance insights.
- No sensitive personal data is intentionally collected.

---

## ☁️ Deployment

This project is designed for **Cloudflare Pages**:

1. Connect the repository to Cloudflare Pages
2. Set build output directory to `public`
3. Deploy automatically on push
